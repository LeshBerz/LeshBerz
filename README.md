## Обо мне

Пишу frontend на React и TypeScript. Больше всего люблю интерфейсы для сложных данных: графы, графики, таблицы — когда информации много и её нужно сделать понятной. Отдельно увлекаюсь алгоритмами.

В командных проектах мне интересна не только разработка: разбираю требования, рисую схемы, планирую работу и с удовольствием беру на себя роль PM.

Выпускник СПбГУ, ПМ-ПУ, «Программирование и информационные технологии», 2026. Живу в Санкт-Петербурге.
